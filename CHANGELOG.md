# Changelog

All notable changes to this project will be documented in this file. The
format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and
the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Installable `fixed_wing_uav` Python package and `uav-dynamics` command
- Strict, versioned TOML aircraft and aerodynamic configuration
- GitHub Actions validation and distribution-building workflow
- Open-source contribution, security, citation, and release documentation

## [0.1.0] - Unreleased

### Added

- Validated illustrative aircraft and aerodynamic data models
- Bounded straight-flight trim and dimensional stability derivatives
- Complete longitudinal and lateral state-space models
- Modal classification, state participation, and time-response simulation
- Deterministic JSON, CSV, PNG, and SVG output artifacts
