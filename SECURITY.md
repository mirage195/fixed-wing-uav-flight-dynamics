# Security policy

## Supported versions

Security fixes are applied to the latest released version. The project is
currently pre-1.0 and does not promise long-term support for older releases.

## Reporting a vulnerability

Use GitHub's private security-advisory form when available. If that is not
possible, email `harshit04beri@gmail.com` with a minimal reproduction and the
affected version. Do not include secrets, export-controlled information, or
sensitive aircraft data in a public issue.

This repository is analysis software, not certified flight software. A model
error, unstable result, or mismatch with a physical aircraft should be handled
as an engineering validation concern as well as a possible software defect.
Do not rely on this project for safety-critical operation.
